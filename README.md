# Flask and MongoDB Assignment

## Project Description

This project is a Flask web application developed as part of the Flask & MongoDB assignment.

The application contains:

1. A JSON API route at `/api`
2. A frontend form
3. MongoDB Atlas integration
4. Success redirect
5. Error handling on the same page

## Technologies Used

- Python
- Flask
- MongoDB Atlas
- PyMongo
- HTML
- CSS
